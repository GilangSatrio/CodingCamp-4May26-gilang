# Product Overview

**To-Do Life Dashboard** is a personal productivity web app built as a single, self-contained HTML page. It combines four panels into one minimal interface:

- **Greeting Panel** — displays current time, date, and a time-of-day greeting
- **Focus Timer** — a 25-minute Pomodoro-style countdown with start/stop/reset
- **Task List** — add, edit, complete, and delete to-do items
- **Quick Links Panel** — user-defined shortcut buttons that open URLs in a new tab

All data is persisted in the browser's **Local Storage**. No backend, no build step, no dependencies — just open the HTML file and use it.

## Target Users
Individual users who want a lightweight, offline-capable productivity dashboard accessible from any modern browser.
